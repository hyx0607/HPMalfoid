# HPMalfoid · 霍格沃茨同期新生资料库

SFW同人角色卡的公开资料维护仓库。当前是研究检查点，不是完整可玩角色卡。

## 数据与状态分开
- data/spells.json：81项魔法、道具与能力记录，稳定ID。不是全系列穷尽。
- data/world-rules.json：9项世界规则；原作概括与本卡玩法分别标注。
- data/daily-event-seeds.json：6类本卡原创日常事件，不是原作确切日期。
- data/sources.json：来源网址和核对范围。

玩家的已学魔法、日期、当前剧本等由聊天内MVU保存。JSON链接不会自动进入模型上下文，也不会自动实现MVU权限约束；需要专门的加载、校验、知识选择和写回适配。

## 可选 CDN
固定发布版本使用 https://cdn.jsdelivr.net/gh/hyx0607/HPMalfoid@COMMIT/data/spells.json ，将COMMIT替换为真实完整提交SHA。不要在正式卡中依赖移动的main分支。
成品卡计划保留内置基础资料；远程更新必须显式选择并校验版本、哈希、稳定ID，失败时保留已有可用资料。玩家资料与存档不上传GitHub。

## 权利与范围
本仓库为非官方同人项目，与原作权利人无关联。Harry Potter相关名称及设定权利归相应权利人。这里仅提供短事实整理、来源链接与本项目原创玩法说明；不附原著、电影、参考卡、参考预设或未授权图片。暂不授予第三方原作素材的开源许可。
